# Phatcenter
Portfolio Website

Đây là dự án Portfolio cá nhân, được xây dựng nhằm giới thiệu thông tin cá nhân, kỹ năng, các dự án đã thực hiện và thông tin liên hệ.

📌 Giới thiệu

Website Portfolio được thiết kế với giao diện hiện đại, tối giản và responsive, giúp người xem dễ dàng tìm hiểu về:

Thông tin cá nhân
Giới thiệu bản thân
Kỹ năng chuyên môn
Các dự án đã thực hiện
Kinh nghiệm học tập/làm việc
Thông tin liên hệ
🚀 Công nghệ sử dụng
HTML5 – Xây dựng cấu trúc website
CSS3 – Thiết kế giao diện và responsive
JavaScript – Xử lý tương tác và chức năng
Git/GitHub – Quản lý mã nguồn và triển khai dự án
